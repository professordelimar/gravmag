# GravMag

Computational tools, numerical experiments and educational examples for **gravimetry and magnetometry**, with emphasis on potential-field methods in geophysics.

## About

This repository brings together Python codes developed for computational applications in gravity and magnetic methods.

The main objective is to provide clear and reusable implementations for forward modeling, processing, filtering, spectral analysis, regression, inversion, synthetic-model generation and interpretation of gravity and magnetic data.

The repository is intended for students, researchers and professionals interested in computational geophysics and potential-field methods.

## Scope

The repository may include implementations related to:

### Gravimetry

- Newtonian gravitational attraction
- Gravity anomalies
- Bouguer and free-air concepts
- Gravity disturbance and gravity anomaly
- Simple geometric bodies
- Spheres, cylinders and prisms
- Forward gravity modeling
- Regional-residual separation
- Spectral analysis
- Upward and downward continuation
- Horizontal and vertical derivatives
- Analytic signal
- Tilt-angle methods
- Edge enhancement
- Euler deconvolution
- Werner-type approaches
- Gravity inversion
- Density estimation
- Synthetic gravity models

### Magnetometry

- Magnetic field representation
- Magnetic anomalies
- Magnetic dipoles
- Magnetization and susceptibility
- Induced and remanent magnetization
- Forward magnetic modeling
- Reduction transformations
- Derivatives and filters
- Analytic signal
- Tilt-angle methods
- Spectral analysis
- Euler deconvolution
- Magnetic inversion
- Susceptibility estimation
- Synthetic magnetic models

### Computational methods

- Numerical linear algebra
- Least-squares methods
- Regression
- Regularization
- Optimization
- Fourier-domain methods
- Spatial-domain filtering
- Grid processing
- Interpolation
- Noise analysis
- Synthetic-data generation
- Numerical visualization

## Installation

Clone the repository:

```bash
git clone https://github.com/professordelimar/gravmag.git
```

Enter the repository:

```bash
cd gravmag
```

Install the basic dependencies:

```bash
pip install -r requirements.txt
```

## Running the codes

Python scripts can generally be executed with:

```bash
python filename.py
```

Jupyter notebooks can be opened with:

```bash
jupyter notebook
```

Specific instructions should be documented inside individual scripts or notebooks whenever additional data, parameters or dependencies are required.
